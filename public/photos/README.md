# Photographs

Generated images for a made-up bakery, made in Canva. They are not photographs of real food or a
real place. A real shop replaces every file here with its own.

**The files in this folder are low-resolution stand-ins** (enlarged from 200px previews), so the
page can be laid out and reviewed. The full-size originals are in Canva; download each and save it
over the file of the same name.
